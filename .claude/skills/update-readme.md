# 更新 README.md 文件

你是一个资深 C++ 网络框架库的文档编写专家。你的任务是更新项目的 README.md 文件，使其成为一个专业、完整、易于理解的 GitHub 项目说明文档。

## 任务目标

分析 Codebus 项目的代码库结构和功能，生成一个包含以下内容的 README.md 文件：
1. **项目简介** - 清晰描述项目的定位、特性和优势
2. **安装说明** - 详细的依赖要求和编译安装步骤
3. **使用方法** - 简单明了的示例代码，展示如何使用主要功能

## 执行步骤

1. **分析项目结构**
   - 读取 `CLAUDE.md` 了解项目定位和模块划分
   - 读取 `CMakeLists.txt` 了解编译配置
   - 探索 `src/` 目录下的各个模块，理解每个模块的功能
   - 查看 `test/` 目录了解使用示例

2. **编写项目简介**
   - 项目的核心定位（C++17 网络框架库）
   - 参考的框架（muduo、sylar）
   - 主要特性和优势
   - 适用场景

3. **编写安装说明**
   - 编译要求（CMake 版本、C++ 标准）
   - 依赖项（从 CMakeLists.txt 和 3rd/ 目录分析）
   - 编译步骤
   - 可选的编译选项

4. **编写使用方法**
   - 提供简单直接的示例代码
   - 展示常用模块的使用方式（如日志、线程、网络等）
   - 代码要符合项目的代码风格规范

5. **生成 README.md**
   - 使用标准的 GitHub Markdown 格式
   - 包含清晰的标题层级
   - 代码块使用语法高亮
   - 添加项目徽章（如果有）
   - 包含目录结构展示

## 代码示例要求

- 示例代码要简洁明了，展示核心用法
- 代码要符合项目的代码风格规范（参考 `.claude/rules/code_style.md`）
- 示例代码要能编译通过（基于项目实际接口）
- 每个示例要有简要说明

## 注意事项

- 文档使用中文编写
- 符合 GitHub 项目说明的最佳实践
- 保持文档的专业性和可读性
